# Security Policy

## Supported Versions

Ored is currently under active development. Security updates are provided
for the latest version available in the `main` and 'ored ai' branch. 

| Version | branch             |supported         |
| ------- | ------------------ | ---------------- |
| latest  | main and ored ai.  |:white_check_mark:|
| older   |                    |:x:               |

## Reporting a Vulnerability

If you discover a security vulnerability in Ored, please report it privately
to the project maintainer rather than opening a public GitHub issue.

Please include:
- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any relevant screenshots, logs, or proof of concept

We will review legitimate security reports and work to address confirmed
vulnerabilities as soon as reasonably possible.
